How do paid calls work?+

Ordinary MCP clients can discover and plan. To commission or query, your client also needs an x402 payment helper that signs with your Hedera testnet wallet locally.

GraphRail’s repository includes examples/agent.ts. Set BUYER_ACCOUNT_ID, BUYER_PRIVATE_KEY and BUYER_MAX_PAYMENT in your local .env, then run npm run example:agent after service availability is restored. Never put private keys into chat or MCP tool arguments.

Configured prices: — per build and — per query. Failed builds retain receipts and need operator repair. Creator revenue splitting is not implemented.

How do I run GraphRail myself?+

From the repository, install Node 22, copy .env.example to .env, and configure Supabase, Hedera testnet and Substreams. Keep credentials on the server.

Run npm ci, npm run db:migrate, npm run setup:storage, and npm run setup:hedera for a fresh install. Prepare a Market deployment slot after reviewing stdout output. Then run npm run setup:check and npm run build.

Start the API with npm start and the worker separately with npm run worker:start (Windows: scripts\start-worker-windows.cmd). The landing page and MCP share port 3000. See the full setup guide for the sequence and existing-install notes.

What is supported on testnet?+

Ethereum Sepolia event indexing, Supabase PostgreSQL storage, and Hedera testnet payments via Blocky. The compiler supports scalar ABI event fields. It rejects arrays, tuples, anonymous or overloaded events, custom aggregations and mainnet definitions.

Discovery and status are free. A ready service supports bounded GraphQL queries, up to 100 rows per entity read. Big integers remain exact decimal strings.

Why are new builds paused?+

The current test deployment hit a StreamingFast database initialization error. Its runner is paused, and new commissions are disabled while that issue is resolved. The live status above reflects the current server configuration.
